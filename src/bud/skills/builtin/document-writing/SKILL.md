# Write and revise a document

Identify the audience, purpose, source material and requested output. Reuse known
preferences and examples. Choose a useful structure for this job rather than imposing a
vendor template. Ask only when a missing decision would materially change the document.
When the person supplies literal content to save exactly, preserve its punctuation and
whitespace. Do not add headings, formatting or a trailing newline to that content.

Read an existing document before revising it. Preserve its useful content, sources and
the person's edits. For a new document, gather evidence and write a complete first draft
that the person can review. Use the research method when the content needs investigation.

Use available workspace or connected-document tools to produce the requested artifact.
Keep an editable source and references. When rendering PDF, slides or another format,
inspect the actual generated output for missing content, clipped text, broken charts
and unreadable layout; repair the source and render again. If that format's tools are
unavailable, explain the missing capability and offer a supported output.

Verify the saved result using a read-back or the tool's confirmed revision. Link or name
the deliverable so it can be found later. For follow-ups, revise the retained artifact
rather than reconstructing it from memory. Saving, replacing, publishing or sharing work
uses the applicable approval flow.
